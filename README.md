# دوائي | إدارة الصيدلية

تطبيق سطح مكتب لإدارة الصيدلية، مبني على Tauri 2 وReact وTypeScript. يتضمن لوحة التحكم وإدارة المنتجات والمخزون والمبيعات والعملاء والمشتريات والتقارير والإعدادات، مع العربية RTL والإنجليزية والوضعين الفاتح والداكن.

## تشغيل الواجهة

يتطلب Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
```

## تشغيل تطبيق سطح المكتب

يتطلب Rust 1.89+ وأدوات البناء الخاصة بمنصة التشغيل (ومنها WebKitGTK على Linux):

```sh
npm run tauri dev
```

## التحقق

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

## الطباعة الحرارية

تُدار الطابعات من **الإعدادات ← إعدادات الطباعة الحرارية**. يدعم التطبيق إيصالات ESC/POS بعرض 58 و80 مم عبر USB أو اتصال الشبكة الخام، مع ملفات إعداد مستقلة لكل طابعة، تحديد الافتراضية، عدد النسخ، الدقة، القص، الشعار والطباعة التلقائية. يمكن اكتشاف أجهزة USB وخدمات الطباعة الحرارية المعلنة على الشبكة عبر mDNS؛ كما يمكن إدخال IP والمنفذ يدويًا (المنفذ الشائع هو 9100).

تعرض شاشة المبيعات معاينة الإيصال قبل الطباعة، ويمكن طباعة نسخة تجريبية أو إعادة طباعة إيصال من سجل الطباعة. يُحوّل الإيصال المعروض في WebView إلى PNG قبل ترميزه كصورة Raster في ESC/POS؛ لذلك تُطبع العربية من الصورة المُشكّلة باتجاه RTL، ولا يُرسل النص العربي الخام للطابعة. يستمر استخدام نافذة طباعة النظام لطباعة A4.

تُحفظ الفاتورة والمخزون أولًا في SQLite؛ فشل الطباعة لا يلغي البيع، ويُسجّل في سجل الطباعة مع إتاحة إعادة المحاولة. تتطلب الطباعة المباشرة أن يدعم الجهاز ESC/POS. قد تحتاج طابعات USB على Linux إلى صلاحيات udev مناسبة، وقد تتطلب بعض أجهزة Windows تعريف USB متوافقًا مع libusb. عناوين الشبكة اليدوية مقيدة بعناوين IP المحلية، واكتشاف mDNS يقتصر على خدمات الطباعة المعلنة ولا يفحص نطاق الشبكة.

اختبارات المشروع تتحقق من ترميز Raster وتسجيل الفشل وإعدادات الواجهة، لكنها لا تستبدل اختبار طابعة فعلية؛ يجب إجراء طباعة تجريبية على موديل الجهاز المستخدم للتحقق من عرض النقاط والقص وجودة الصورة.

لبناء مثبّت Windows بصيغة `.exe`، شغّل يدويًا سير العمل `Windows installer` من تبويب Actions. سيُرفَع المثبّت كـ artifact لمدة 30 يومًا.

## التحديثات التلقائية

يعرض التطبيق تنبيهًا عند توفر إصدار أحدث ويثبّت التحديث الموقع بعد موافقة المستخدم.

لتمكين التحديثات في GitHub Actions، أضف الأسرار التالية في إعدادات المستودع:

- `TAURI_SIGNING_PRIVATE_KEY`: محتوى مفتاح التوقيع الخاص الذي أنشئه Tauri.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: كلمة مرور مفتاح التوقيع.

لا ترفع المفتاح الخاص أو كلمة المرور إلى المستودع. ينشر سير عمل Windows إصدارًا موقّعًا وملف `latest.json` إلى GitHub Releases، ويستخدم التطبيق هذا الملف للتحقق من التحديثات.

تتضمن قاعدة البيانات العملات وأسعار الصرف والمنتجات والتشغيلات وسجل حركات المخزون والمبيعات والمدفوعات. تمثل كمية كل منتج عددًا صحيحًا بوحدته المخزنية الأساسية (مثل قرص أو ملليلتر).

تُخزن قاعدة البيانات في مجلد AppData الخاص بالتطبيق، وتُدار ترقيات المخطط عبر ترحيلات SQLite. يُنشأ نسخ احتياطي متسق قبل تطبيق ترحيل على قاعدة موجودة.
