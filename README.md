# دوائي | إدارة الصيدلية

تطبيق سطح مكتب لإدارة الصيدلية، مبني على Tauri 2 وReact وTypeScript. الواجهة الحالية هي المرحلة الثانية: هيكل التطبيق، لوحة التحكم، التنقل، العربية RTL والإنجليزية، والوضعان الفاتح والداكن.

## تشغيل الواجهة

يتطلب Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
```

## تشغيل تطبيق سطح المكتب

يتطلب Rust 1.89+ وأدوات البناء الخاصة بمنصة التشغيل (ومنها WebKitGTK على Linux):

```sh
npm run tauri dev
```

## التحقق

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

لبناء مثبّت Windows بصيغة `.exe`، شغّل يدويًا سير العمل `Windows installer` من تبويب Actions. سيُرفَع المثبّت كـ artifact لمدة 30 يومًا.

## التحديثات التلقائية

يعرض التطبيق تنبيهًا عند توفر إصدار أحدث ويثبّت التحديث الموقع بعد موافقة المستخدم.

لتمكين التحديثات في GitHub Actions، أضف الأسرار التالية في إعدادات المستودع:

- `TAURI_SIGNING_PRIVATE_KEY`: محتوى مفتاح التوقيع الخاص الذي أنشئه Tauri.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: كلمة مرور مفتاح التوقيع.

لا ترفع المفتاح الخاص أو كلمة المرور إلى المستودع. ينشر سير عمل Windows إصدارًا موقّعًا وملف `latest.json` إلى GitHub Releases، ويستخدم التطبيق هذا الملف للتحقق من التحديثات.

أقسام المنتجات والمخزون والمبيعات وغيرها تظهر حاليًا كوجهات تنقل أولية. تتضمن قاعدة البيانات أساس العملات وأسعار الصرف، والمنتجات والتشغيلات وسجل حركات المخزون. تمثل كمية كل منتج عددًا صحيحًا بوحدته المخزنية الأساسية (مثل قرص أو ملليلتر).

تُخزن قاعدة البيانات في مجلد AppData الخاص بالتطبيق، وتُدار ترقيات المخطط عبر ترحيلات SQLite. يُنشأ نسخ احتياطي متسق قبل تطبيق ترحيل على قاعدة موجودة.
