# دوائي | إدارة الصيدلية

تطبيق سطح مكتب لإدارة الصيدلية، مبني على Tauri 2 وReact وTypeScript. الواجهة الحالية هي المرحلة الثانية: هيكل التطبيق، لوحة التحكم، التنقل، العربية RTL والإنجليزية، والوضعان الفاتح والداكن.

## تشغيل الواجهة

يتطلب Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
```

## تشغيل تطبيق سطح المكتب

يتطلب Rust وأدوات البناء الخاصة بمنصة التشغيل:

```sh
npm run tauri dev
```

## التحقق

```sh
npm test
npm run build
```

أقسام المنتجات والمخزون والمبيعات وغيرها تظهر حاليًا كوجهات تنقل أولية. ستُنفذ قواعد العمل والبيانات في مراحل لاحقة داخل Rust، ولا يحتوي هذا الهيكل على بيانات أعمال فعلية.
