# دوائي | إدارة الصيدلية

تطبيق سطح مكتب لإدارة الصيدلية، مبني على Tauri 2 وReact وTypeScript. الواجهة الحالية هي المرحلة الثانية: هيكل التطبيق، لوحة التحكم، التنقل، العربية RTL والإنجليزية، والوضعان الفاتح والداكن.

## تشغيل الواجهة

يتطلب Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
```

## تشغيل تطبيق سطح المكتب

يتطلب Rust 1.89+ وأدوات البناء الخاصة بمنصة التشغيل (ومنها WebKitGTK على Linux):

```sh
npm run tauri dev
```

## التحقق

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

أقسام المنتجات والمخزون والمبيعات وغيرها تظهر حاليًا كوجهات تنقل أولية. قاعدة البيانات في هذه المرحلة تحتوي على أساس الإعدادات والعملات وأسعار الصرف فقط؛ تُنفذ وحدات العمل في مراحل لاحقة داخل Rust.

تُخزن قاعدة البيانات في مجلد AppData الخاص بالتطبيق، وتُدار ترقيات المخطط عبر ترحيلات SQLite. يُنشأ نسخ احتياطي متسق قبل تطبيق ترحيل على قاعدة موجودة.
